# CITS-to-go Android App

Android app for the **CITS-to-go** portable C-ITS receiver.

The app reads packets from the Seeed Studio XIAO ESP32-C5 over USB serial, decodes the binary `CTG1` COBS/CRC frames emitted by the firmware, records streams to PCAP, and forwards the captured raw packet payloads to MQTT using the same packet-topic style as the original OpenTrafficMap receiver firmware.

## Running the app

1. Flash the CITS-to-go firmware to the XIAO ESP32-C5.
2. Connect the XIAO to the Android phone with a USB-C data cable.
3. Open the app.
4. Grant USB permission.
5. Configure the MQTT broker URI and node ID.
6. Start capture.
7. Use **Record PCAP** to choose an output file if local capture is needed.
8. Confirm packet, PCAP, and MQTT counters increase.

The bridge runs as a foreground service with a partial wakelock while capture is active, so USB capture and MQTT forwarding continue while the phone is locked. MQTT publishes are retried through an app-private disk spool when the broker is offline.

PCAP output is classic libpcap with `DLT_IEEE802_11` link type and raw captured 802.11 frame bytes.

## MQTT output

The packet stream matches the upstream OpenTrafficMap receiver firmware:

```text
Topic:   its/<nodeid>/packet
Payload: raw binary packet bytes
QoS:     0
Retain:  false
```

The app also publishes retained `its/<nodeid>/status` messages (`online`/`offline`), `its/<nodeid>/info`, and periodic `its/<nodeid>/stats`.

## Compile the debug APK

Run from the `android-app/` directory:

```bash
nix-shell --run './gradlew assembleDebug'
```

The debug APK will be written to:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Install it with the below command, or send it to the phone and install with a file explorer:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
