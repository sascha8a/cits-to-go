# CITS-to-go Android App

Android app for the **CITS-to-go** portable C-ITS / ITS-G5 receiver.

The app reads packets from the Seeed Studio XIAO ESP32-C5 over USB serial, saves them as PCAP, and forwards them to MQTT using the same packet-topic style as the original OpenTrafficMap receiver firmware.

## Running the app

1. Flash the CITS-to-go firmware to the XIAO ESP32-C5.
2. Connect the XIAO to the Android phone with a USB-C data cable.
3. Open the app.
4. Grant USB permission.
5. Configure MQTT broker details if MQTT forwarding is needed.
6. Start capture.
7. Confirm packet counters increase and PCAP output is being written.

## Capture pipeline

The app uses a service-based pipeline:

```text
USB reader
  -> CITS binary/ASCII parser
  -> buffered PCAP writer
  -> app-private MQTT spool
  -> interval MQTT publisher
```

Important behavior:

- USB reading does not wait for MQTT.
- PCAP writing is the primary capture path.
- MQTT publishing drains queued packets in intervals.
- If MQTT fails, packets remain in the app-private spool for retry.
- The foreground service uses a persistent notification so Android is less likely to suspend capture while the phone is locked.

## Android permissions and background behavior

The app uses:

- USB host permission for the connected ESP32-C5.
- A foreground service for continuous capture.
- Notification permission on recent Android versions.
- Wake/Wi-Fi locks while capture is running.

For long captures:

1. Start the app.
2. Grant USB permission when Android asks.
3. Grant notification permission if requested.
4. Start capture/MQTT.
5. Keep the **C-ITS USB Bridge** foreground notification active.
6. On heavily optimized Android builds, set battery mode for this app to **Unrestricted**.
